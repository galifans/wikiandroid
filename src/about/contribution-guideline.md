# 🤝 贡献指南

欢迎为 AndroidStuff 贡献内容！无论是修正错误、补充文章，还是完善代码，都欢迎你的参与。

## 贡献方式

1. **修正错误**：发现内容错误或笔误，提交 PR 修正
2. **补充文章**：撰写高质量的 Android 技术文章
3. **完善代码**：改进站点功能与样式
4. **反馈建议**：通过 Issues 提出改进建议

## 提交流程

1. Fork 本仓库
2. 创建分支：`git checkout -b feature/new-article`
3. 编写内容（Markdown 格式）
4. 提交并推送
5. 发起 Pull Request

## 写作规范

- 文章放在对应模块目录（如 Kotlin 文章放 `/language/kotlin/`）
- 文件名使用小写中划线（如 `kotlin-basics.md`）
- 文章开头添加 frontmatter（title / icon / description）
- 代码示例需可运行、注释清晰
- 引用外部资料注明来源

## 注意事项

- 请勿发布无授权转载的内容
- 请勿发布与 Android 无关的内容
- 尊重他人版权与劳动成果
