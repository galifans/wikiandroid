# Android 学习路线（2026 最新版）

> 本文为 Android 开发者提供一条从零到进阶的系统学习路径。

## 一、第一阶段：语言基础（1-2 个月）

- **Kotlin**：语法、空安全、扩展函数、高阶函数、协程基础
- **Java 基础回顾**：面向对象、集合、泛型、反射
- **数据结构与算法**：数组、链表、树、哈希表、排序与查找

## 二、第二阶段：Android 核心（2-3 个月）

- **四大组件**：Activity、Service、BroadcastReceiver、ContentProvider
- **Fragment 与 Intent**
- **View 体系**：布局、绘制流程、事件分发
- **数据存储**：SharedPreferences、Room、DataStore
- **网络编程**：HTTP 协议、OkHttp、Retrofit、JSON 解析

## 三、第三阶段：Jetpack 与架构（2 个月）

- **Jetpack 全家桶**：Lifecycle、ViewModel、LiveData、Room、Paging、Navigation
- **架构模式**：MVC → MVP → MVVM → MVI
- **依赖注入**：Hilt / Koin
- **Jetpack Compose**：声明式 UI 开发

## 四、第四阶段：进阶与原理（3 个月）

- **性能优化**：启动、卡顿、内存、电量、包体积
- **系统原理**：Handler、Binder、AMS/WMS、APK 打包
- **工程实践**：Gradle、Git、CI/CD、单元测试

## 五、第五阶段：面试与项目（持续）

- 阅读[面试指南](/interview/)沉淀高频考点
- 打造 1-2 个有深度的实战项目
- 阅读优秀开源项目源码（如 Now in Android、Sunflower）

> 配合[面试指南](/interview/)与[实战项目](/projects/)效果更佳。
