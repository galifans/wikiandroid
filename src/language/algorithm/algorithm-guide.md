# 算法刷题指南

> 一份可执行的算法刷题路线，覆盖面试最常考察的题型。

## 一、第一阶段：基础数据结构（2-3 周）

| 专题 | 代表题目 |
|------|----------|
| 数组 | 两数之和、三数之和、合并区间 |
| 链表 | 反转链表、环形链表、合并两个有序链表 |
| 栈与队列 | 有效的括号、最小栈、滑动窗口最大值 |
| 哈希表 | 字母异位词分组、最长连续序列 |

## 二、第二阶段：核心算法（3-4 周）

| 专题 | 代表题目 |
|------|----------|
| 双指针 | 盛最多水的容器、移动零 |
| 滑动窗口 | 无重复字符的最长子串、最小覆盖子串 |
| 二分查找 | 搜索旋转排序数组、寻找峰值 |
| 二叉树 | 层序遍历、最近公共祖先、二叉树的最大深度 |

## 三、第三阶段：进阶算法（3-4 周）

| 专题 | 代表题目 |
|------|----------|
| 动态规划 | 爬楼梯、最长递增子序列、打家劫舍、背包问题 |
| 回溯 | 全排列、组合总和、单词搜索 |
| 贪心 | 跳跃游戏、分发饼干 |
| 图 | 岛屿数量、课程表（拓扑排序） |

## 四、刷题方法论

1. **五步刷题法**：审题 → 暴力解 → 优化 → 写代码 → 总结
2. **模板化**：二分、回溯、DP 都有固定模板，先背模板再理解
3. **复杂度意识**：每次提交前先想时间/空间复杂度
4. **错题本**：记录卡壳点，每周复习一次
