# 🧮 数据结构与算法

算法是面试与工程能力的底层支撑，也是进阶大厂的必经之路。

## 必学内容

### 数据结构
- 数组、链表、栈、队列
- 哈希表、树（二叉树、BST、Trie）、堆
- 图（邻接表/矩阵、DFS/BFS）

### 算法思想
- 双指针、滑动窗口
- 二分查找、分治
- 动态规划、贪心
- 回溯、递归

## 刷题建议

1. 按**专题**刷题，而非随机刷题
2. 每道题思考**时间复杂度**与**空间复杂度**
3. 一题多解，比较不同解法的优劣
4. 定期复习，使用遗忘曲线安排回顾
