# 简历与项目经验建议

> 简历是面试的敲门砖，项目经验是技术深度的直接体现。

## 一、简历要点

### 基本信息
- 姓名、电话、邮箱、GitHub/技术博客链接
- 技术栈标签：Kotlin、Jetpack Compose、协程、性能优化

### 技能描述（量化）

```
✗ 熟悉 Android 开发
✓ 精通 Kotlin 与协程，主导 3 个项目的网络层与架构搭建
✓ 通过启动优化将冷启动耗时从 2.1s 降至 1.2s（降低 43%）
✓ 负责组件化改造，将 5 个业务模块拆分独立编译
```

### 项目经验（STAR 法则）

| 要素 | 说明 |
|------|------|
| Situation | 项目背景与业务规模 |
| Task | 你负责的职责 |
| Action | 具体的技术方案与行动 |
| Result | 可量化的成果（数据！） |

## 二、项目选型建议

### 初学者（1-2 年经验）
- 完整的开源项目：Now in Android、Sunflower
- 自研项目：资讯类 App（含缓存、推送、多模块）

### 进阶（3 年+）
- 高并发场景：IM 应用、直播应用
- 技术深度：性能优化专项、组件化改造、自研框架

## 三、面试表达技巧

1. **先结论后细节**：一句话概括，再展开
2. **多讲"为什么"**：技术选型的原因
3. **展示量化思维**：能用数据说结果
4. **承认不足**：诚实面对不会的问题，展示学习能力

## 四、常见错误

- ✗ 罗列技术名词堆砌
- ✗ 项目描述泛泛而谈（"负责开发 App"）
- ✗ 简历造假（技术深度一聊就穿帮）
