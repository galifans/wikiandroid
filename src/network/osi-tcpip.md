# 计算机网络体系

> 计算机网络体系结构分为 OSI 七层模型和实际使用的 TCP/IP 四层模型。本章从物理层到应用层逐层梳理核心概念。

## 一、体系结构分类

| OSI 七层模型 | TCP/IP 四层模型 |
| --- | --- |
| 应用层 | 应用层 |
| 表示层 | 应用层 |
| 会话层 | 应用层 |
| 传输层 | 传输层 |
| 网络层 | 网络层 |
| 数据链路层 | 物理接入层 |
| 物理层 | 物理接入层 |

## 二、物理层

物理层实现主机和网络之间的物理连接，规定与传输媒体接口相关的特性。

### 通信方式

| 通信方式 | 说明 |
| --- | --- |
| 单工通信 | 只能由 A 向 B 发送，通信单向 |
| 半双工通信 | 同一时间只能单向，不能同时收发 |
| 全双工通信 | 同一时间既能接收又能发送，效率最高 |

### 常见引导型传输媒体

- **双绞线：** 分为屏蔽双绞线（STP）和非屏蔽双绞线（UTP）。两根线绞起来可以有效减少相互之间的电磁干扰。
- **同轴电缆：** 由内导体铜制芯线、绝缘层、网状编织的外导体屏蔽层、塑料保护外层组成，抗干扰性好，广泛用于较高速率的传输。
- **光缆：** 由非常透明的石英玻璃拉成细丝，由纤芯和包层构成双层通讯柱，分为单模光纤和多模光纤。

### 信道复用技术

| 复用方式 | 原理 |
| --- | --- |
| 频分复用 | 根据波的频率不同，将不同频段的波用于不同通信 |
| 时分复用 | 将时间分割为时间段，按时间段区分信息类别（同步时分复用） |
| 统计时分复用 | 时分复用的改进：有数据才占用时隙，动态分配（异步时分复用） |
| 光分复用 | 光的频分复用，用不同频率的光携带不同信息 |

## 三、数据链路层

数据链路层将上层的数据转化为数据帧发送到链路上，以及把接收到的帧中的数据取出交给网络层。

### 通信方式

- **点对点通信：** 只能两点之间的通信，常见协议是 PPP。
- **广播通信：** 一对多通信，常见协议是 CSMA/CD（载波监听多点访问/冲突检测）。

### 核心要解决的问题

1. **封装成帧：** 在数据前后分别添加首部和尾部构成帧，方便接收端确定帧的首尾（帧定界符），并定义最大传输单元（MTU）表示一次可传输的最大长度。
2. **透明传输：** 内容中若出现与帧定界符相同的字符，在字符前加上转义字符，称为字符填充或字节填充。
3. **差错检测：** 比特在传输过程中可能产生差错，最常用的差错检测算法是 CRC（循环冗余检验）。

## 四、网络层

网络层向上提供简单灵活的、无连接的、尽最大努力交付的数据报服务。

### IP 协议族

IP 协议是 TCP/IP 体系中最主要的协议之一，常说的 IP 协议其实是一个协议族，还包含配套协议：

| 协议 | 全称 | 作用 |
| --- | --- | --- |
| ARP | 地址解析协议 | 将 IP 地址转化为实际物理地址（MAC 地址），存储在 MAC 地址表中 |
| ICMP | 网际控制报文协议 | 差错情况和异常情况的反馈，分为询问报文和差错报告报文 |
| IGMP | 网际组管理协议 | 控制和管理多播、组播 |

### IP 地址分类

- **A 类：** 前 8 位为网络位，后 24 位为主机位，首位为 0。
- **B 类：** 前 16 位为网络位，后 16 位为主机位，前两位为 10。
- **C 类：** 前 24 位为网络位，后 8 位为主机位，前三位为 110。
- **D 类：** 用于多播（组播），前四位为 1110。
- **E 类：** 保留地址，前五位为 11110。

## 五、传输层与应用层

**传输层：** 负责端到端的通信，核心协议是 TCP（可靠、面向连接）和 UDP（高效、无连接），详见《TCP 与 UDP 详解》。

**应用层：** 直接为用户提供服务，常见协议有 HTTP/HTTPS、FTP、SMTP、DNS、SSH 等。
