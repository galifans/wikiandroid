# ☕ Kotlin 学习路线

> Kotlin 已成为 Android 官方推荐语言，掌握它是现代 Android 开发的必备技能。

## 一、Kotlin 基础（1-2 周）

- 变量与数据类型、空安全（`?`、`!!`、`?:`）
- 控制流：`if`、`when`、循环
- 面向对象：类、继承、接口、数据类、密封类
- 函数：默认参数、命名参数、高阶函数、Lambda

## 二、Kotlin 进阶（1 周）

- **扩展函数与扩展属性**
- **泛型**：协变、逆变、星投影、reified
- **作用域函数**：`let`、`run`、`with`、`apply`、`also`
- **委托**：类委托、属性委托、`by lazy`

## 三、协程与 Flow（2 周）

- 协程基础：`launch`、`async`、`suspend`、调度器
- 结构化并发：`CoroutineScope`、`Job`、`SupervisorJob`
- **Flow**：冷流与热流、操作符、背压处理

## 四、Kotlin 与 Android 结合（持续）

- `kotlin-android` 插件与扩展
- 协程 + Retrofit + Room 的实践组合
- 使用 Kotlin 重构 Java 项目
