# 学习路线

系统性的学习路径规划，帮助你从零开始、循序渐进地掌握 Android 开发。

## 路线合集

| 路线 | 适合人群 | 预计周期 |
|------|----------|----------|
| [Android 学习路线（2026 最新版）](android-roadmap.md) | 零基础入门 / 转行 Android | 6-12 个月 |
| [Kotlin 学习路线](kotlin-roadmap.md) | 已掌握 Java 的开发者 | 2-4 周 |
| [Jetpack Compose 学习路线](compose-roadmap.md) | 有 Android 基础，转向声明式 UI | 1-2 个月 |
| [Android 版本演进与特性](android-version-history.md) | 所有开发者，补全版本常识 | 1 周 |

## 学习建议

1. **先动手再理论**：每个知识点都配合一个 Demo 练习
2. **重视源码**：面试深水区往往考察源码理解，例如 Handler、Binder
3. **坚持输出**：通过写博客、开源项目沉淀自己的知识体系
4. **关注官方**：优先阅读 [Android 官方文档](https://developer.android.com/) 与 [Kotlin 官方文档](https://kotlinlang.org/)
