# 常见问题

## 1. 网站的内容是免费的吗？

是的，WikiAndroid 完全免费开源，基于 MIT License 发布。

## 2. 如何订阅更新？

- 关注 GitHub 仓库的 Star 与 Watch
- 定期访问本站查看新文章

## 3. 可以转载文章吗？

可以，但请注明出处（文章来源链接）与作者信息。

## 4. 如何联系维护者？

通过 GitHub Issues 或 Discussions 交流。

## 5. 如何提交建议或纠错？

参考[贡献指南](/about/contribution-guideline.md)，直接提交 PR 或 Issues。

## 6. 网站会更新哪些内容？

- 高频面试题持续更新
- 源码解析专题
- 技术前沿（Compose、KMP 等）
