# 面试准备计划

> 一份可执行的中大厂 Android 面试备考计划（建议 6-8 周）。

## 第一阶段：基础巩固（第 1-2 周）

第一阶段的学习内容与目标如下：

| 内容 | 目标 |
|------|------|
| [语言基础](/interview/basics.md) | 掌握高频题，能流利回答 |
| 数据结构和算法 | 刷 LeetCode HOT 100 |
| 四大组件与 View | 结合 Demo 复习 |

## 第二阶段：源码深挖（第 3-4 周）

第二阶段的学习内容与目标如下：

| 内容 | 目标 |
|------|------|
| [Handler 源码](/network/handler/handler-source.md) | 能画出完整流程图 |
| [Binder 机制](/system/binder/binder-mechanism.md) | 理解一次拷贝与架构 |
| Activity 启动流程 | 理解 Zygote/AMS 协作 |
| APK 打包流程 | 理解完整构建链路 |

## 第三阶段：进阶与项目（第 5-6 周）

第三阶段的学习内容与目标如下：

| 内容 | 目标 |
|------|------|
| [性能优化](/advanced/performance/) | 掌握优化手段与工具 |
| 架构设计 | 能讲解项目架构演进 |
| 项目复盘 | 准备 2-3 个有深度的项目 |

## 第四阶段：冲刺（第 7-8 周）

- 每日模拟面试（口述回答）
- 复盘错题与薄弱点
- 投递简历，先小厂后大厂

## 每日时间分配（建议 4-6 小时）

每日时间分配建议如下：

| 时间 | 内容 |
|------|------|
| 上午 | 算法 1 小时 + 八股文 2 小时 |
| 下午 | 源码阅读 1 小时 + 项目 1 小时 |
| 晚上 | 模拟面试 + 复盘总结 |
