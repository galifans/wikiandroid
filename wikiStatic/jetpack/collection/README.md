# Collection 集合库

内存友好的 Android 集合：ArrayMap、ArraySet、LruCache、不可变集合、FlowExt。

## 文章列表

- [Collection 集合库详解](collection-guide.md) — ArrayMap / ArraySet / LruCache / 不可变集合 / FlowExt

## 核心概念

1. **ArrayMap**：内存更省的双数组 Map，适合小数据量
2. **ArraySet**：ArrayMap 的单元素版本
3. **LruCache**：LRU 内存缓存
4. **不可变集合**：ImmutableList / ImmutableMap / ImmutableSet
5. **FlowExt**：协程 Flow 相关扩展
