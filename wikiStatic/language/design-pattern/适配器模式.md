# 适配器模式

> 将一个类的接口转换成客户希望的另一个接口，使原本因接口不兼容而无法一起工作的类可以一起工作。

## 定义与功能

**定义**：接口转换，让不兼容的类协同工作。

**功能**：转换匹配，目的是**复用已有功能**而非实现新接口。在适配器内实现功能，称为智能适配器。

## 优点与缺点

**优点**：

- 更好的复用性
- 更好的扩展性

**缺点**：过多使用适配器会让系统零乱，不易整体把握。

## 本质与适用场景

**本质**：转换匹配，复用功能。

**适用场景**：

- 想使用已有类但接口不符合需求
- 创建可复用的类，可能和不兼容的类一起工作（需要什么就适配什么）
- 已有多个子类但无法逐一适配时，用对象适配器直接适配父类

## Android 中的实现：RecyclerView.Adapter

RecyclerView.Adapter 的标准写法如下：

::: code-tabs

@tab:active Java

```java
recyclerView.setAdapter(new MyAdapter());

private class MyAdapter extends RecyclerView.Adapter<RecyclerView.ViewHolder> {
    @Override
    public RecyclerView.ViewHolder onCreateViewHolder(ViewGroup parent, int viewType) {
        // 创建 ViewHolder
    }
}
```

@tab Kotlin

```kotlin
recyclerView.adapter = MyAdapter()

private class MyAdapter : RecyclerView.Adapter<RecyclerView.ViewHolder>() {
    override fun onCreateViewHolder(parent: ViewGroup, viewType: Int): RecyclerView.ViewHolder {
        // 创建 ViewHolder
    }
}
```

:::

`RecyclerView` 通过 `Adapter` 适配数据与视图的转换：`Adapter.createViewHolder()` 创建 ViewHolder，`onBindViewHolder()` 绑定数据，将不同数据源统一适配为列表项。
