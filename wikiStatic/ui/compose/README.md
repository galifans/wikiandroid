# 🧩 Jetpack Compose

Android 现代声明式 UI 框架。

## 核心概念

1. **声明式 UI**：状态驱动，UI = f(state)
2. **重组（Recomposition）**：状态变化自动更新 UI
3. **Modifier**：链式修饰（padding、clickable、size）
4. **状态管理**：`remember` / `mutableStateOf` / ViewModel
5. **与 View 互操作**：`AndroidView` / `ComposeView`
